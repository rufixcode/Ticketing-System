# MallTix: A Web and Mobile-Based Ticket Reservation and Event Management System for Mall Cinemas and Convention Venues

## Short Project Description

*MallTix* is a web and mobile-based ticket reservation and event management system designed for a mall's cinema and convention venues. The system provides customers with a convenient platform to browse movies and events, view schedules, reserve cinema seats or event tickets, and receive digital tickets with QR codes for validation.

The system supports *three cinemas and one to two convention/event venues*, allowing administrators to manage movies, screenings, venues, events, reservations, and tickets through a centralized platform.

MallTix follows an integrated structure of *Venue → Screening/Event → Reservation → Ticket*, providing a unified reservation workflow for both cinema screenings and mall events.

### Technology Stack

* *Frontend:* React Native with Expo
* *Backend:* Laravel REST API
* *Database:* MySQL
* *Authentication:* Laravel Sanctum
* *Version Control:* Git / GitHub

### Core Features

* User registration and authentication
* Movie and event browsing
* Cinema screening schedules
* Cinema seat reservation
* Event ticket reservation
* Digital ticket generation
* QR code-based ticket validation
* Reservation history
* Cinema, venue, movie, and event management
* Administrative dashboard
